# Apps Area and Stick Privacy Policy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An "Apps" section on the home page, a Stick page at `/apps/stick/` and its privacy policy at `/apps/stick/privacy/`, in the site's own style.

**Architecture:** Hand-written static HTML reusing `css/style.css` tokens and classes; shared app-card styles go in `css/style.css`, app-page-only styles in a new `css/apps.css`. App pages set the saved theme with a tiny inline script and load no other JS.

**Tech Stack:** HTML5, CSS custom properties, GitHub Pages (static, `main` at `/`), `node server.js` for local checks, headless Chrome for screenshots.

**Spec:** `docs/superpowers/specs/2026-11-25-apps-area-design.md`

## Global Constraints
- Zero dependencies, no build step, no new JS files (AGENTS.md).
- Colours only via existing CSS custom properties; the one exception is the app brand colour on app icon tiles: Stick `#c6ff3d` with `#0b0b12` text.
- Asset links on app pages are root-absolute (`/css/style.css`, `/apps/stick/privacy/`), so pages work with or without a trailing slash.
- Contact in the policy: `oneguyatwork@gmail.com`. Effective date: 25 November 2026. Developer: Sidharth Sreekumar.
- Instagram link: `https://www.instagram.com/th3_on3guy/`.
- Work on branch `feat/apps-area`; never push to `main` without Sidharth's go.

## Review Focus
1. **Narrow phones (360 px):** no horizontal scroll on any new page or the home section. Check: Chrome screenshot at 360 px width and `document.documentElement.scrollWidth <= 360` (Task 4).
2. **All 4 themes:** text stays readable on app pages in `midnight`, `emerald`, `amber`, `light`. Check: screenshots with `localStorage.sdd_theme` set to each (Task 4).
3. **No JavaScript / blocked storage:** app pages still render (default theme) if `localStorage` throws. Check: inline script wrapped in try/catch, grep in Task 1.
4. **Deep links:** `/apps/stick` (no slash) and `/apps/stick/privacy` resolve and style correctly on GitHub Pages and locally. Check: curl through `node server.js` in Task 4.
5. **Home page untouched elsewhere:** existing sections, terminal and simulators still work. Check: `node -c js/*.js`, home screenshot, and a diff limited to nav/drawer/new section (Task 3).
